# Undergraduate Scientific Computing & In-Situ Lab Utilities

This repository serves as an open-source portfolio of custom-built computational utilities developed to automate data processing, statistical analysis, and data visualization across various undergraduate laboratory practicals. 

Rather than relying on post-hoc spreadsheet processing, these tools are engineered to provide **immediate, bench-side analytical feedback** during active experimental sessions.

---

## Operational Paradigm: Mobile In-Situ Deployment

Unlike traditional data science workflows that ingest static, pre-existing database files, the notebooks in this repository are architected as **active laboratory instruments**.

* **Mobile Bench Deployment:** Notebooks are deployed via Google Colab, allowing for direct, seamless access on mobile devices and tablets within the wet-lab environment.
* **On-the-Fly Entry:** Raw observational metrics (e.g., colony counts, zone diameters, absorbance values) are inputted directly into pre-structured Python arrays in real time at the bench, minimizing transfer errors.
* **Instant Statistical Feedback:** This approach enables real-time algorithmic computation, curve-fitting, and data validation while the practical is still underway, turning raw observations into immediate scientific insights.
